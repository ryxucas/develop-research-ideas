# 从领域文献发现研究机会

## 建立领域图谱

只给出领域时，先检索和梳理，不要求用户先提供 idea。范围过大时，先给出少量问题分支及其边界；采用有说明的暂定范围继续，只有会实质改变筛选的资源或目标缺失才提问。

用综述和代表性工作建立导航，再以原始研究核实判断。兼顾奠基研究、近期变化、最近邻工作与反面结果，不按年份逐篇罗列。按问题组织：哪些问题推动领域发展；主流方法依赖什么条件；新增方法改变了哪项能力；还有哪些结果没有解释清楚。不得从少量论文推断整个领域。

## 横向综合，而非逐篇摘局限

比较多篇论文的问题、共同假设、对象、机制、对照、评估终点与结论边界。先检查结论是否可比：数据、指标、预算或任务不同，不能直接称为矛盾。

按适用性选择 2–3 个入口，不强制全部使用：

| 入口 | 要追问什么 | 必须排除的误判 |
|---|---|---|
| 共同假设 | 哪个普遍依赖的假设在重要情境下可能不成立？ | 假设不现实不自动意味着结果受影响 |
| 结论差异 | 不同结果能否由一个未控制的因素解释？ | 不可比实验造成的表面冲突 |
| 失效边界 | 方法在哪些实际重要条件下失效，原因是什么？ | 任意极端条件下失败但没有研究价值 |
| 评估遗漏 | 现有指标是否回答了实际关心的终点？ | 多测一个指标就宣称创新 |
| 条件变化 | 新能力、数据、负载或使用方式改变了哪些旧判断？ | 仅替换更新模型或数据集 |
| 机制与简化 | 有效性来自哪个机制，是否存在更简单的解释或方法？ | 将组件消融本身当作重大贡献 |
| 结构类比与重述 | 换一个目标、粒度或邻域机制能否产生可检验问题？ | 概念拼接、表面比喻、为了跨领域而跨领域 |

为每个研究机会连起这条可追溯的链：
**论文中的具体观察 → 尚未解释或回答的问题 → 为什么重要 → 候选问题 → 最近邻可能已覆盖的部分。**

标明观察是作者报告、跨论文综合还是自己的推断。附关键来源位置；尚未核实的机会只能叫候选，不能写成已确认空白。不要为了让 idea 显得强而贬低前人：前人的范围选择可以合理，新问题也可以成立。

## 检验研究价值

追问：即使“没人做过”，为什么值得知道答案？结果将改变哪项认识、方法选择、系统设计或现实决策？理论问题可提供概念澄清、可证明边界或解释能力，不强求直接用户收益。

区分“补充了一个场景”与“这个场景能够检验现有结论是否成立”。区分“增加模块”与“模块实现了回答问题所需的机制”。正结果、无提升或相反结果分别能说明什么？无显著差异可能来自证据不足，不能自动包装成有价值的负结果。

## 针对候选寻找反例

候选形成后，用任务、机制、场景、终点及其同义词组合检索；查最接近论文的参考文献与后续引用，主动寻找已解决、部分覆盖或反驳该问题的工作。

- 已完整回答且无重要新条件：淘汰，不靠改标题保留。
- 部分覆盖：指出剩余未知，重新判断其价值，不能把剩余空白默认当贡献。
- 证据不足：标注待核实，并指出哪项核查会决定去留。
- 新证据启发不同问题：允许短暂再构思，合并同质候选，不无休止扩张。

## 输出的最小形态

按本轮需要展示：领域的主要问题与变化；2–3 项带来源的关键观察；少量实质不同的候选；推荐理由、最大不确定性及下一项决策性核查。已足够明确时可只保留一项；没有强候选时如实说明，给最有希望的线索与所缺证据，不凑数或承诺顶会录用。

## 假设示例：模型路由

以下仅演示推理，不代表真实文献结论，不得用作引用或预设推荐答案。

假设阅读发现：一些方法估计难度，一些预测模型表现，部分任务中模型规模与表现并不单调。可以追问：“问题难度是否足以代表升级模型的收益？”其价值在于可能改变路由器的学习目标。

随后必须核查收益预测、模型选择等邻近术语下的研究。如果前人已经完整回答，就淘汰；若只缺一个数据集，先判断它能否检验重要边界。不能把“困难≠升级收益”当成未经验证的创新结论。候选也可以来自不确定性识别或路由开销，但只有核心未知、机制或可观察预测不同，才算不同方向。
